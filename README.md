# JanAwaaz - Voice of the People

A civic engagement platform where citizens can report local infrastructure problems like broken roads, garbage, electricity outages, water leaks, and more. Citizens can create posts, upvote issues, comment, track progress, and view issues on a map. Authorities can accept, update, and resolve issues.

## Features

### For Citizens
- Report infrastructure issues with photos and location
- Upvote issues to increase visibility
- Comment on issues and engage with the community
- Track progress of reported issues
- View issues on an interactive map
- See issues in their district feed

### For Authorities
- Accept reported issues
- Update issue status and progress
- Add official responses
- Resolve issues

### For Admins
- Moderate the platform
- Manage users and content

## Tech Stack

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript (no frameworks)

### Backend
- Node.js
- Express.js
- MongoDB Atlas with Mongoose

### APIs & Libraries
- MapLibre + OpenStreetMap (maps)
- Cloudinary (media uploads - free tier)
